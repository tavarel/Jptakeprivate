# ADR 0001 — Record architecture decisions

Status: accepted · 2026-10-07

## Context
Decisions get forgotten; in interviews and code reviews the question is always "why this way?".

## Decision
Record every significant decision as a short ADR in `docs/decisions/NNNN-title.md`:
Context → Decision → Consequences. Never edit an accepted ADR; supersede it with a new one.

## Consequences
A few minutes per decision; a clear history of reasoning.
